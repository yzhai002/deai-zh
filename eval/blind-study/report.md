# 盲测报告（2026-09-22）

匿名配对评审 + 事实保真 + 确定性指标，验证 deai-zh 技能的改写效果。设计参照 blader/humanizer #229 的盲测方法论，缩小规模。

## 设计

- **输入**：8 篇模型默认风格文本（新闻语域，同题对照语料 calibration/ai），每篇约 400-500 字。
- **改写**：2 个独立子代理，各自先完整阅读 SKILL.md，再执行完整工作流程（标记痕迹 → 起草 → 检查 → 终稿），各处理 4 篇。代理不知道本研究的目的。
- **评审**：2 个匿名裁判，只见随机化后的 A/B 对（pairN-A.txt / pairN-B.txt，位置由固定种子随机分配，映射存 mapping.json，裁判不可见），不知任何版本来源。1 个事实核查员逐一对照输入与改写。
- **折扣**：全部子代理跑在同一模型家族（GLM）上，单家族裁判偏差未消除；裁判与改写者来自同一模型。

## 结果

### 1. 确定性指标（evaluate.py）

|---|---|---|
| 词表命中 | 8 | **0** |

| 均匀句长跑 | 0 | 0 |

**诚实记录**：均匀句长 0→0——这批输入本身没有触发 4 句 ±20% 的检测器，本次研究对 §7（均匀句长）假设**没有提供任何证据**。要验证节奏层，需要用刻意均匀的输入重测（如 eval/cases/03 的输入那种）。

### 2. 匿名配对评审

- **裁判二：8/8 选改写**。其 A/B 标注经与文件核对完全一致，引用证据明确（"磨出来的""实打实的""图的是""多了一条线"被认定为真人语感；落选版的病灶集中在"充分彰显/值得一提的是/注入新活力/迈上新台阶/结尾升华"，与校准词表高度吻合）。
- **裁判一：定性证据 8/8 支持改写，但其 A/B 位置标注混乱**（例：pair2 描述"实惠"优于"发展红利"，实际"实惠"在 A、其答案却写 B）。按引用证据计数。方法论教训：裁判的 A/B 标注必须核对到文件才能入表。
- **合计 16/16 偏好改写。**

裁判指出的改写稿残留问题（改进 backlog）：
- 官方导语处理不一致：07 删掉了"记者从交通部门获悉"，05 保留了"记者从自然资源部门获悉"——§17 应区分匿名权威（删）与具名信源（保留）。
- 压缩过头：pair3、pair6 的改写被批"主谓宾串珠、节奏单一"——删痕迹时没做节奏参差，恰是 §7 要求的反面。
- 个别惯性展望句残留（pair1 结尾"竞争力应该会更强"被批收得平）。

### 3. 事实保真

- **零新增事实**：8 篇改写没有任何一处编造（无幻觉，符合技能反编造规则的预期）。
- 硬数字、日期、专名 100% 保留。
- 最常见丢失是**信源归属**（"相关专家表示""分析人士指出""记者从X获悉"）——与 §17"匿名权威删掉"的指令方向一致，属于按规则行事，但"记者从X获悉"这类具名信源不该删（见上面 backlog）。
- 两处内容性丢失：05 的"优化矿产资源供应格局"、06 的"文旅消费持续回暖"整句没了；07 的"标志着重大突破"定性被删（§13 要求删夸大，边界情况）。
- 程度弱化（"不可替代"→"实打实"、"宝贵经验"→"参考价值"）符合 §13 删夸大的预期。

## 结论

1. **质量假设成立**：改写稿盲评 16/16 胜出、零幻觉、硬事实零丢失。
2. **词汇层清零且未引入新痕迹**：与 #229 不同，本次没有观察到格言收尾/均匀节奏恶化（裁判二指出的是改写压缩过度导致的节奏单一，方向相反）。
3. **§7 节奏假设仍未验证**：需要一轮以均匀句长输入为主的补充盲测。
4. **单家族裁判折扣**：结论为强信号但非定论；建议人工抽读 2 篇改写稿做第二裁判。
