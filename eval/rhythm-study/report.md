# 节奏专项盲测（2026-09-22）

验证 §7「均匀句长」假设——上一轮盲测（report.md）因输入本身不均匀而未覆盖，本次补测。

## 设计

- **输入**：4 篇刻意均匀的文本（每句 7-11 字，主题各异：缓存运维、图书馆、订单流程、湖景），确定性检测器对每篇各触发 1 处均匀跑，输入不含词汇类痕迹——纯节奏样本。
- **改写**：1 个子代理，加载 SKILL.md v1.1.1（含本轮新增的压缩节奏指引）。**折扣**：提示中点名了"这四篇是 §7 样本"，存在引导可能；更严格的复测应不点名。
- **评审**：1 个匿名裁判，只见随机化 A/B 对（映射存 mapping.json）。

## 结果

| 指标 | 输入（4 篇） | 改写（4 篇） |
|---|---|---|
| 均匀句长跑 | 4 | **0** |
| 词表命中 | 0 | 0 |

句长分布变化（字数/句）：

- u1: [10, 9, 10, 8, 8, 8, 9, 10] → [22, 28, 8, 19]
- u2: [9, 9, 10, 8, 9, 7, 9, 8] → [25, 20, 8, 17]
- u3: [10, 9, 11, 11, 11, 11, 10, 10] → [18, 11, 21, 27]
- u4: [9, 10, 11, 10, 10, 10, 10, 9] → [10, 21, 10, 37]

裁判 4/4 选改写（A/B 标注与文件核对一致）。证据全部落在节奏维度：原稿被批"一句一周期""顶针式机械串联、节奏均一"（输入为制造均匀使用了前句尾词作下句开头的顶针结构，被裁判独立识别为机器感）；改写被认可"长短相间、有呼吸感""短句定锚再长句合并事实"。

裁判指出的改写残留：u1 两句因果衔接生硬；u4 并列景物清单缺少视点串联——打散节奏后的行文组织仍有打磨空间，但不影响"更自然"的方向判定。

## 结论

1. **§7 假设在代理执行层面成立**：改写把均匀句长跑从 4 清到 0，且盲评确认这是节奏改善而非质量下降。
2. **与 #229 的对比成立**：旧版英文 humanizer 盲测中节奏指标恶化（均匀节奏 60→101）；本技能的 §7 + 第 3 步自查闭环在中文上把节奏指标清零——当初加 §7 的目的达成。
3. 折扣：改写提示点名了 §7（有引导嫌疑）、裁判单家族、样本仅 4 篇。更严格的版本：不点名重测、双家族裁判。
