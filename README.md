# 去AI味（deai-zh）

去AI味把 AI 味的中文改写得像人写的，不改变原意。它只是一个 Markdown 技能文件，任何支持 skills 的 agent 都能加载。

英文版在 [deai](https://github.com/yzhai002/deai)（基于 [blader/humanizer](https://github.com/blader/humanizer)，MIT 协议）；本项目复用其框架，观察名单、示例和模式全部本地化为中文。

## 安装

用 Skills CLI 安装：

```bash
npx skills add yzhai002/deai-zh --global
```

去掉 `--global` 只装到当前项目。手动安装时，把 `SKILL.md` 复制到 agent 的技能目录。

## 用法

贴上文本直接说：

```
帮我把这段文字去掉 AI 味：

[贴文本]
```

想保留自己的语感，先贴两三段自己写的文字做样本，技能会模仿样本的句长、用词和标点。给文件路径时只改散文，代码、命令、配置和链接不动。

## 它能做什么，不能做什么

它让文字**读起来更好**。它**不能**骗过 AI 检测器：检测器看的是全文的统计特征，不是表面的词和句式。用这个技能是为了让稿子像人写的，不是为了过检测。

## 26 个模式

模式按强度和出现频率编号。§1–§5 见一次就改；标 *单独偏弱* 的要同段落多处痕迹共现才动手，因为谨慎的作者可能有意那样写。

### A. 铺垫代替直说

| # | 模式 | 例 | 处理 |
|---|------|----|------|
| 1 | **不是X而是Y** | "不仅仅是X，更是Y"、"这并不意味着X。它意味着Y。" | 直接说出观点 |
| 2 | **单句收尾与戏剧性断句** | "这才是真正的关键。" | 删掉复述的收尾；碎片合并成主张 |
| 3 | **伪深刻格言** | "说到底，效率是一种修行。" | 换成具体主张 |
| 4 | **铺垫式开场** | "接下来让我们深入探讨"、"值得注意的是" | 删铺垫直接给要点 |
| 5 | **与假想敌辩论** | "这并不是说X"、"有人可能会说……但是" | 删辩护，留真实主张 |

### B. 规则化的节奏

| # | 模式 | 例 | 处理 |
|---|------|----|------|
| 6 | **强行三段式** | "启发、灵感和洞见" | 意义需要几个就几个 |
| 7 | **均匀句长** | 连续四句以上长度几乎相同 | 拆长、并短、允许某句跑长 |
| 8 | **破折号与省略号**（*单独偏弱*） | "这项技术——曾被视为不可能——" | 换逗号、冒号、句号 |
| 9 | **重复句首与模板结构** | "它……它……它……"、"首先其次最后" | 合并句子或换主语 |
| 10 | **堆叠限定词**（*单独偏弱*） | "可能在一定程度上或许" | 只留来源支持的限定 |
| 11 | **被动与无主句**（*单独偏弱*） | "需要指出的是"、"已被优化" | 说清谁在做 |

### C. 夸大与借势

| # | 模式 | 例 | 处理 |
|---|------|----|------|
| 12 | **AI 高频词** | "赋能……助力……深耕……打造" | 用平实的话；词表见 SKILL.md |
| 13 | **夸大重要性** | "标志着重要里程碑，前景广阔" | 留事实删意义，收在具体事实上 |
| 14 | **模糊关联** | "与多家头部机构保持密切合作" | 写明来源给的关系 |
| 15 | **尾随的拔高从句** | "……，彰显了团队的技术实力" | 留事实 |
| 16 | **广告腔** | "坐落于风景秀丽的……不二之选" | 直接说这个东西是什么 |
| 17 | **借用权威** | "专家表示……" | 有名字有原话才留，绝不编造 |
| 18 | **回避具体动词** | "扮演着重要角色"、"进行了优化" | 用"是/有"和具体动词 |

### D. 规则化排版

| # | 模式 | 例 | 处理 |
|---|------|----|------|
| 19 | **加粗装饰** | "**高并发**、**高可用**" | 去加粗；标签列表改成散文 |
| 20 | **装饰性标题** | "🚀 上线阶段：" | 删装饰，用平实标题 |
| 21 | **中英文标点混用**（*单独偏弱*） | "批量导入,白名单(可选)" | 统一全角标点 |

### E. 草稿残留

| # | 模式 | 例 | 处理 |
|---|------|----|------|
| 22 | **聊天残留** | "当然可以！……希望这对你有帮助！" | 删壳留内容 |
| 23 | **知识截止声明与猜测** | "由于公开资料有限，推测……" | 写明缺什么，或删整句 |
| 24 | **标题在首句重复** | "## 性能" + "速度很重要。" | 让标题干活 |
| 25 | **描述上一版** | "此函数用于替代……" | 描述现在的行为 |
| 26 | **机器指纹** | `[cite: 3]`、`utm_source=`、零宽字符 | 删残渣；留主张和干净链接 |

## 检查

`scripts/evaluate.py` 检查一段改写里脚本看得见的痕迹：机器指纹、破折号省略号、高频词、均匀句长、丢失的数字。它判断不了意思和声音，是关卡不是评审。

```bash
python3 scripts/evaluate.py 原文.md 改写.md
python3 scripts/evaluate.py --all   # 检查 eval/cases/ 里全部用例
```

词表有语料依据：`scripts/calibrate.py` 比较模型默认输出与真人新闻语料的词频（语料在 `calibration/`），数据见 `calibration/report.md`，结论见 `calibration/notes.md`。

## 完整示例

**改写前（AI 味）：**

> 当然可以！以下是关于杭州的介绍。杭州坐落于风景秀丽的江南水乡，底蕴深厚，是一座将历史文化与现代活力完美融合的城市。西湖不仅是一处景点，更是这座城市的精神象征，见证了千年的沧桑变迁。近年来，杭州大力发展数字经济，致力于打造创新高地，为城市发展注入了新动能。可以说，杭州的未来前景广阔，值得期待。希望这对你有帮助！

**改写后：**

> 杭州在长三角南边，京杭大运河的南端。城市的一半围着西湖，老城区的巷子在湖东边。过去十年这里互联网公司多起来，阿里在城西的园区里养了几万人，地铁因此往那个方向修了好几条。秋天桂花开的时候满城是甜味，本地人说是市树香樟打底的底子，其实是满觉陇的桂树。

（细节需来自原文或用户；没有就问，不编。）

## 来源

- 模式框架与工作方法来自英文版 [deai](https://github.com/yzhai002/deai)，其源头是 [blader/humanizer](https://github.com/blader/humanizer)（MIT）与维基百科 ["Signs of AI writing"](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)。

## 版本历史

- **1.1.1** - 按盲测（eval/blind-study/report.md）裁判批评修正：§17 区分匿名权威与具名信源（"记者从某部门获悉"保留，无名字的"专家表示"才删）；§7 补充压缩指引（并句后若段落变成等长主谓宾串珠就再拆）。
- **1.1.0** - 用真人新闻语料校准词表（澎湃、中新网 8 篇对照模型默认输出 8 篇）：§12 新增"充分、绽放、强劲、重要意义、注入、备受瞩目"等 AI 独有的强信号词；evaluate.py 扩充词表与短语表（新增"专家表示"等借用权威短语和"充分+动词"搭配）；校准数据与结论入库（calibration/）。无新模式。
- **1.0.0** - 首个版本。26 个本地化模式，五组结构（铺垫、节奏、夸大、排版、残留）沿用英文版框架；新增中文特有模式：§9 作文模板结构、§18 回避具体动词（"进行+名词"）、§21 中英文标点混用。配 `scripts/evaluate.py` 中文版评测脚本（中文分句、字数统计）与三个黄金用例。
